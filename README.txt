
# AFLW Match Tracker App

This package converts your AFLW Match Tracker into a Progressive Web App (PWA).

## Features
- Installable on iPhone, iPad, Android, and desktop
- Offline support
- Full-screen app experience
- Home screen icon

## How to Use

### iPhone / iPad
1. Upload files to any web host (GitHub Pages, Netlify, Vercel, etc.)
2. Open the site in Safari
3. Tap Share → Add to Home Screen

### Android
1. Open the site in Chrome
2. Tap Install App

## Included Files
- index.html
- manifest.json
- service-worker.js
- app icons
